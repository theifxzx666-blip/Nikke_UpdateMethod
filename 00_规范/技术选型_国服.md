## 一、取数链

| 环节 | **主选** | 备选 | **明确放弃** | 判据 / 放弃原因 |
| :--- | :--- | :--- | :--- | :--- |
| 版本识别 | `dumpsys package com.tencent.nikke` 取 `versionName` + catalog 的 `mtime` + 字节数 | — | 只看版本号 | 同版本热更后 catalog 会变，三要素才唯一 |
| 拷 catalog | `su -c cp files/com.unity.addressables/*.json → /sdcard/<临时>` 再 `adb pull` | — | 直接 pull `files/` | 外部存储对 `shell` 用户不可读 |
| **基线** | **直接用设备上历史 catalog**（按日期天然共存） | 自己拍快照 | 手工做基线 | 国服 catalog 不会删旧，09-10 / 09-30 同时躺在目录里。这是相对国际服最大的便利 |
| catalog 解析 | `cn_catalog.py`（三段二进制：KeyData / BucketData / EntryData） | — | 当 JSON 读 | 文件后缀是 `.json`，内容是**自定义二进制**，不是 JSON |
| 分卷识别 | `cn_index.py` 出 `03_catalog分卷索引.tsv`，按内容特征挑 7 卷 | — | 按 `m_ProjSpan` 名挑 | 同 span 有多份（`NIKKE CONTENTS` 出现 3 次），按名挑必然配错 |
| 键 → 文件 | catalog `m_InternalIds` 里**直接就是** `bundle名_<32hex>.bundle` | — | 三级表 + chunk 偏移 | 国服没有 `store.cdb`，只有 Addressables |
| diff 口径 | **以 `m_InternalIds` 为准** | — | 只看 `m_EntryDataString` | 大厅动画（`spine/standing/...`）不注册 entry，只看 entries 会整批漏（E-40） |
| 实体缓存 | `files/UnityCache/Shared/<h1>/<h2>/__data` | — | 按目录名反推 bundle | `<h1>` == bundle 内部 `AssetBundle.m_Name`，与 catalog 的 `_<md5>` **无关**（E-43） |
| 缓存内容判定 | **UnityPy 解包读内部资源名** | — | `grep -a <键名>` / `grep -a <资源名>` | `UnityFS` 块 LZ4 压缩 + container 是裸哈希，raw grep 恒 0（E-44） |
| 大文件批量拉 | `cn_pull_probe.py`（逐个子进程 `su -c cp` 到 `/sdcard`，再整目录 pull） | — | 长命令拼 12 个 `cp` | 含引号的长命令会被截断，报 `No such file or directory` |
| 解包 | UnityPy 1.25.4，**逐文件单独起子进程** | — | 批量循环 | 个别 bundle 会 C 层 segfault（rc=139），`try/except` 抓不住 |
| 图集导出 | 直接用 bundle 里的 `TextAsset`（`.skel` / `.atlas`）+ `Texture2D` | — | 自己拼 atlas | 三件套全在包里，`c162_01_skillcut` 已验证 |

## 二、文本链

| 环节 | 做法 | 判据 |
| :--- | :--- | :--- |
| 文本库 | `sa/<version>/lss/Locale_*.lss`，**SQLite**，表名 = 文件名 | `sqlite_master` 直接看 |
| 列结构 | 只有 `Key, zh-CN, IsSmart` 三列 | 国际服是 11 列 5 语，**国服 5 语交付不成立** |
| 角色名 | `Locale_Character` 的 `<编号>_name` | `513_name` = 小美人鱼 |
| 时装名 | `Locale_CharacterCostume` 的 `<cID>_<NN>_costume_name` | `280_01_costume_name` = 危险小姐 |
| 时装说明 | 同表 `<cID>_<N>_description` | 「罗珊娜的时装 / 通过任务PASS获得」 |
| 主线剧情 | `Locale_MainScenario`，键 `d_main_<章>_<段>_<轨>_<序>` | 39 章 `d_main_39_*` 1,860 行 |
| 活动剧情 | `Locale_MainScenario`，键 `event_<活动代号><部分>_*` | `event_unbreakablesphere1/2` 共 3,356 行 |
| EX / 档案馆剧情 | `Locale_SubScenario`，键 `event_<代号>_*` | `event_claymore` 1,527 行、`event_doutsiders` 603 行 |
| 番外篇 | `Locale_SideStory`，键 `s<NNN>_<段>_*`，标题 `s<NNN>_<段>_title` | `s004_01_title` = `EDEN SPEAR : 1` |
| 活动名 / 小游戏文案 | `Locale_Event` | `EventBM_*`（Bubble March）、`story_EX_event_name_011 = CLAY,MORE!` |

> **活动名在 `Locale_Event` 里未必有**：UNBREAKABLE SPHERE / D-OUTSIDERS 的中文名在 `Locale_Event` 查不到，
> 只能从剧情正文的收尾行确认（`UNBREAKABLE SPHERE : To be Continued`）。查不到不要断言「没有」。

## 三、脚本清单（`05_脚本/主线/`）

| 脚本 | 作用 | 输入 → 输出 |
| :--- | :--- | :--- |
| `cn_catalog.py` | 解析国服 Addressables catalog（三段二进制） | `*.json` → `{key_data, bucket_data, entries, internal_ids}` |
| `cn_index.py` | 扫一个目录下全部 catalog，出分卷索引 | `cn_index.py <catalog 目录> --out x.tsv` |
| `cn_diff_vol2.py` | 7 卷逐卷 diff，以 `m_InternalIds` 为准 | `cat_all/` → `out/分卷diff_v2.tsv` |
| `cn_roles.py` | diff → cID → 资源类型 → 角色/时装名 | `out/分卷diff_v2.tsv` + `lss/` → `out/本期新增角色.tsv` |
| `cn_pull_probe.py` | 按路径清单逐个 `su -c cp` 后整目录 pull | 路径清单 → 本地 `*.bundle` |
| `cn_probe_bundles.py` | 逐文件子进程跑 UnityPy，识别包内容 | `*.bundle` → json（类型统计 / 资源名） |

`cn_diff_vol2.py` 顶部的 `VOLS` 是**本期配对结果**，下期必须重配（`cn_index.py` 出表后按特征挑）。

## 四、与国际服的对照（一眼看出为什么不能混写）

| 环节 | 国际服 | 国服 |
| :--- | :--- | :--- |
| 清单 | `com.shiftup.patch/<桶>/catalog.ndb`（SQLite）+ `chunk/store.cdb` | `files/com.unity.addressables/` 下的 `*.json`（二进制，7 卷） |
| 分桶 | `core / dp / saus / ja / fd / en / ko` | 无桶，按 `m_ProjSpan` 分卷 |
| 键 → 文件 | 三级表 + chunk 偏移 + zstd 拼装 | `m_InternalIds` 直接给文件名 + hash |
| 缓存 | `runtime_data/cache/<A>/<B>/__data`（可能 `NKAB` 需解密） | `files/UnityCache/Shared/<h1>/<h2>/__data`（**明文 `UnityFS`**） |
| 基线 | 更新前自己快照 | 历史 catalog 天然共存 |
| 文本 | `.lss` 11 语 | `.lss` **仅 `zh-CN`** |
| 特有结构 | — | 和谐 / 未和谐**两套卷**同名同键、内容不同 |
| 预埋 | 也有，但量小 | **一次大更顺带下发数期资源**（本期 21 个角色 + 莉可丽丝联动全套） |
