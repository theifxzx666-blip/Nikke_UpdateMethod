# 详版模板（`00_本期概览.md` + `YYYY-MM-DD_更新内容一览.pdf`）

> 详版给**自己和复现用**：完整推理链、证据、翻车记录都留在里面。
> 本期实测 48 页 / 46 KB。章数不固定，按内容走，但**章节顺序固定**。

---

## 章节骨架

| # | 章节 | 必含 | 篇幅 |
| :-: | :--- | :--- | ---: |
| 0 | 版本三要素 | versionName / catalog mtime·字节数 / 语音包文件数 + 采集日期 + 设备号 | 半页 |
| 1 | 一页速览 | 本期新增 6 行表（角色 / 皮肤 / 活动 / 主线 / 卡池 / 其他）+ 缩略图墙 | 1 页 |
| 2 | 新角色 | 每角色 1~2 页：立绘 + 技能表 + 爆裂首帧 | N 页 |
| 3 | 新皮肤 | 每件 1 页大图 + 归属说明 | N 页 |
| 4 | 活动 | 插画全览 + 排期 + 收益表 + 道具图标 | 2~3 页 |
| 5 | 主线 | 章节结构 + 地图点位 + 剧情概要 + 剧情插画 | 3~5 页 |
| 6 | 角色动画 | 大厅站立（每时装 GIF 缩略）+ 爆裂特写（首帧 + 分层时序甘特图） | 2~3 页 |
| 7 | 关卡莱彻 | 立绘 / 拆件 / 零件透视 / 判定表 / 3D 模型 | 2~4 页 |
| 8 | **本包收录了什么** | 汇总表：分类 × 数量 × 说明（**所有数字的唯一出处**） | 1 页 |
| 9 | 技术说明 | 六层结构 / 三件做不到的事 / 取景与裁头 / 已知边界 | 1~2 页 |
| 10 | 附录 | 目录树 + 文件命名规则 + 校验结果 | 1 页 |

## 硬约束

| 项 | 要求 |
| :--- | :--- |
| 页面容器 | `.page { height: 266 mm; overflow: hidden }` —— 溢出会**静默截断**，每页出完必须截图核 |
| 图片路径 | **绝对 `file://`**，不用相对路径（headless 丢图） |
| 数字 | 全部从 `_素材清单.csv` / `00_汇总.tsv` 的合计行取，**不在此处另算**（E-03） |
| 数字与实物矛盾时 | 改文档，不改实物；并回写清单 |
| 翻车记录 | **必须留**。这是详版存在的意义 —— 简版可以删 |
| 校验 | `pymupdf` 读页数 + 每页 `get_pixmap` 出图，逐页看一遍 |

## 生成方式

```bash
"$VENV_PY" make_pdf_v2.py
```

`make_pdf_v2.py` 内部：拼 HTML → `_构建\报告.html` → Chrome headless → PDF → 回读校验。
缓存目录 `_构建\PDF缓存\`：**可整块删，重跑像素级一致**（本期实测 0.000%）。

## 一句话原则

> 详版回答「**我们怎么知道是这样的**」。
> 如果读者只想知道「是什么」，去看简版。
