# 简版模板（`YYYY-MM-DD_更新内容简版.pdf`）

> 判据只有一句：**读者拿来就能用的留，解释「我们怎么得出的」删。**
> 不设固定页数。8-13 期实际约 8~14 页。

---

## 必含 5 章（顺序固定）

| # | 章节 | 内容 | 篇幅 |
| :-: | :--- | :--- | ---: |
| 1 | **本期有什么** | 6 行表：角色 / 皮肤 / 活动 / 主线 / 卡池 / 动画。每行给数量 + 一句话 | 1 页 |
| 2 | **新角色** | 每人 1 张立绘 + 6 行（名字 / cID / 稀有度 / 爆裂阶段 / CV / 技能名） | 每人 1/2 页 |
| 3 | **活动与主线** | 各 1 页：活动给插画墙 + 排期；主线给章节 + 剧情概要 | 2 页 |
| 4 | **素材汇总表** | 分类 × 文件数 × 说明。数字与详版第 8 章**完全一致** | 1 页 |
| 5 | **明细表目录** | 明细表在哪、怎么查、字段含义一行 | 1/2 页 |

---

## 必不含

| 删掉的东西 | 原因 |
| :--- | :--- |
| 方法论、技术路线 | 读者不需要知道怎么拆的 |
| 踩坑记录、翻车说明 | 属详版 |
| 脚本名、命令、参数 | 属 Skill |
| 「为什么这么做」 | 属详版 |
| 历史对比、往期回顾 | 只讲本期 |
| 未采项说明 | 属 `未采与放弃.md` |
| `.note` / `.warn` 注释块 | **0 个** |

---

## 硬约束

| 项 | 要求 |
| :--- | :--- |
| 每页字数 | ≤ 300 字 |
| 图 | 每页至多 1 张主图，**不拼图**；图注 1 行，不写解释 |
| 注释块 | 0 个 |
| 数字 | 与详版同源，不另算 |

---

## 生成方式（关键）

**从详版 HTML 删出来，不重写。** 同一个 `make_pdf_v2.py`，用环境变量控制：

```bash
BRIEF=1 "$VENV_PY" make_pdf_v2.py     # 只渲染白名单页 → _简版.pdf
```

```python
BRIEF = os.environ.get("BRIEF") == "1"
BRIEF_PAGES = {0, 1, 2, 4, 8}          # 页索引白名单，按当期内实际章节号改
```

**为什么不能另写一个脚本**：另写必然导致两份数据各自维护，一定会分裂（E-03 就是这么来的）。

## 自检

1. 页数在合理区间，每页无溢出
2. 搜索全文：不能出现「Timeline」「Spine」「bundle」「UnityPy」「脚本」
3. 数字与详版第 8 章逐项比对，全部相等
4. 每页截图看一遍，无破图
