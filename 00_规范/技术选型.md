## 六、被推翻过的结论（别再信）

| 旧结论 | 现状 | 推翻依据 |
| :--- | :--- | :--- |
| 爆裂「做不到能播的动画」，只能交图层 + 时序 | **错**。`skillcut` 动画一直在骨架里 | 打开骨架 `__spine.info()` 直接列出 3~4 条动画 |
| `sprite.texture` 加密不可解 | **错**。是未加密的 ASTC 5×5 | 长度公式 `ceil(w/5)×ceil(h/5)×16` 精确成立 |
| 国际服有 `icons-dynamic` 合集包 | **错**。全桶搜只命中无关的 dynamicprefabcontroller | 多部件体现在 `SubResourceId` 多行结构 |
| `NOSTALGIA` 是个突称号 | **错**。是桃乐丝转盘皮名（`Locale_CharacterCostume:233_01`） | 文本原文 + 描述 |
| 番外篇要全采 6 篇 | **错**。只采本期新增，本期没有 | 国际服 8-13 patch notes 无 Side Story 条目 |
| 文本「5 语齐全」 | **错**。实测 9 语 / 11 列，含 `es` 且非空率 100% | `pragma table_info` + 逐列 `count(*)` 实测（2026-10-26） |
| `00_资源库\文本\原始文本库_lss\` 是国际服文本 | **错**。是国服 9-30 的：3 列 / 13,385 行 / 含 `Locale_Cn*` | 目录内 `_文本库说明.md` 自证来源为 PC 国服 `runtime_data`（E-47） |
| 8-13 的 152.8.7 可以当 10-29 基线 | **错**。中间隔 4~6 期，当前已含 c513、cID 前沿 993 | 读当前 `Locale_Character` 实测（E-49） |
