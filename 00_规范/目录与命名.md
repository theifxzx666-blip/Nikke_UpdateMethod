# 目录与命名

> 本期目录树为**实测结构**，下期照此复制。差异必须能解释。

---

## 一、顶层结构

```
版本更新\
├── AGENTS.md                    # 入口：铁律 + 路由 + 停止点
├── 迁移说明.md                   # 旧路径 → 新路径 对照表
├── 00_规范\                      # 本目录
├── 01_采集明细\                  # 明细表（跨期）
├── 02_Skills\                   # 可复用产线
├── 03_历史\<期次>\               # 已完成期次，原封不动
├── 04_作业区\<期次>\             # 下一期在这里开工
├── 05_脚本\{主线, 归档}\
└── 06_回收站\<日期>_<原因>\
```

**期次命名**：`YYYYMMDD_<服务器>`，服务器 ∈ `国际服 / 国服`。例 `20260813_国际服`。

## 四、唯一源裁决（防重复，硬约束）

同一份二进制**只允许一个物理位置**。两处都要能打开时用**硬链接**（同 inode，物理一份）。

| 内容 | 实体在 | 另一侧 |
| :--- | :--- | :--- |
| 爆裂 GIF | `01_新角色\<角色>\爆裂动画\` | 07 硬链接 |
| 爆裂贴图 | `07_角色爆裂特写\<角色>\<分类子目录>\` | 01 的 `特效贴图\` 硬链接 |
| 剧情插画 | `05_主线_47-48章/05_图片资源/剧情插画/` | `07_关卡莱彻\关底BOSS\` 硬链接 |
| 活动剧情文本 | `03_活动\<活动>\剧情文本\` | `05_主线\04_剧情文本\活动剧情\<代号>\` 硬链接 |

**排除项**：`06_角色大厅站立动画` 的 `_action_首帧.png` 与 `_idle_首帧.png` 字节可能相同，属语义巧合，**不许合并**（E-21）。

清单里 `mode` 列记 `硬链接`（nlink>1）/ `复制`（nlink=1），一眼看出谁是真身。

## 五、命名规范

| 类型 | 规范 | 例 |
| :--- | :--- | :--- |
| 角色目录 | `<中文名>_c<ID>` | `QUEEN（真）_c870` |
| 皮肤目录 | `<皮肤名>_c<ID>_<NN>` | `冬日雅居_c871_02` |
| 大厅动画目录 | `<中文名>_c<ID>_<NN>_<时装>` | `雪子_c871_00_默认` |
| 活动目录 | `<活动名>（<代号>）` | `PERSONA ON FRONTLINE（ce009）` |
| 爆裂 GIF | `c<ID>_<NN>_skillcut.gif` | `c871_00_skillcut.gif` |
| 大厅 GIF | `c<ID>_<NN>_<idle\|action>.gif` | `c870_01_idle.gif` |
| 首帧 | `<同名>_首帧.png` | `c870_01_idle_首帧.png` |
| 贴图 | 保留原始对象名 | `fx_c010_cut_scene_atlas_blen.png` |
| 剧情插画 | `eventscene_<活动>_<序>.png` | `eventscene_chap_47_01.png` |
| 中间件 | `_` 前缀 + 进 `_构建\` | `_构建\报告.html` |
| 说明文档 | `00_说明.md`（每目录一份） | — |
| 回收站 | `<日期>_<原因>\` + `_为什么进站.md` | `20261026_<原因>/`（本期实例：旧版单层爆裂 GIF） |

**中文名以 `00_索引\角色代号中文名对照表.xlsx` 为准**，不许自创。读不到就停下问。

## 六、三条不可违反

1. **不物理删除**。淘汰物 move 进 `06_回收站\`，附 `_为什么进站.md`。只允许 `rmdir` 空目录。
2. **中间件不进清单、不进顶层**。`_构建\` 整块可删可重建，删了重跑必须像素级一致（本期实测 0.000%）。
3. **期目录内不建第一期以外的编号**。`01~07` 是固定分类位，新增分类往后追加，不复用旧号。
