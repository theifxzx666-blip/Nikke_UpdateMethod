# 版式（深底衬线 · 满出血）

> 实测基线：20260813 国际服详版 39 页 / 简版 9 页。
> 全部样式集中在 `make_pdf_v2.py` 的 `CSS` 常量里，**改版式只改那一段，不写内联色**。

---

## 一、视觉基调

参考 https://www.blablalink.com/events/nikke4th/ 的实测取色（`4th anniv` 页）。

| 角色 | 变量 | 色值 | 用途 |
| :--- | :--- | :--- | :--- |
| 页面底色 | `--bg` | `#231f1e` | 深棕黑（不是纯黑，带暖调） |
| 更深衬底 | `--bg-deep` | `#1b1716` | 图片容器的 letterbox 底 |
| 卡片底 | `--panel` | `#2b2523` | 技能块、表格行 |
| 卡片高光 | `--panel-2` | `#332c29` | 悬停/嵌套层 |
| 正文 | `--ink` | `#e9e5e0` | 雾白，不是纯白（纯白在深底上发刺） |
| 正文次级 | `--ink-2` | `#c4bdb7` | 导语、表格值 |
| 次要文字 | `--mut` | `#8d8792` | 图注、页脚、坐标说明 |
| 强调金 | `--gold` | `#c9a227` | 罗马数字、极细分隔线、链接、数字 |
| 金线淡 | `--gold-dim` | `rgba(201,162,39,.30)` | `h2` 下边线 |

**字体**

| 用途 | 变量 | 字族 |
| :--- | :--- | :--- |
| 标题 / 正文 | `--serif` | Georgia → Times New Roman → Source Han Serif SC → Noto Serif SC → SimSun |
| 图注 / 标签 / 页码 | `--sans` | Microsoft YaHei UI → PingFang SC |
| 代码 / 数值 | 直接写 | Consolas → Cascadia Mono |

> 中文衬线在 Windows 上大概率落到 **SimSun**（宋体）。20pt 以上可用，9pt 正文会偏细——所以正文字号下限是 9.4pt，技能正文单独降到 7.2pt 并换 `--ink-2`。

**印刷保真**：`html,body,.page,.cover{ -webkit-print-color-adjust:exact; print-color-adjust:exact; }`
少了这行，Chrome 会把深底"优化"成白底黑字。

## 二、页面几何

```css
@page { size:A4 portrait; margin:0; }
.page { width:210mm; height:296.5mm; padding:14mm 16mm 11mm; overflow:hidden;
        page-break-after:always; display:flex; flex-direction:column; }
```

| 项 | 值 | 说明 |
| :--- | :--- | :--- |
| 页面 | 210 × 296.5 mm | **不是 297**。正好 297 时 Chrome 取整会多吐一页空白 |
| 内边距 | 上 14 / 左右 16 / 下 11 mm | 下边距 11 mm 是裁切判据的阈值，见 §六 |
| 可用内容区 | **178 × 271.5 mm** | `210-32` / `296.5-25` |
| 满出血 | `margin:0` + `.page` 自带底色 | 底色铺到纸边，四面无白框 |

`.page` 是 `overflow:hidden` —— **内容超了被静默裁掉，不报错**。这是最高发的翻车点。

## 三、页型清单

### 1. 封面 `.cover`

整幅出血 + 三张立绘压右下方 + 底部渐变压暗层。

```
.cover (padding 20/18/16)
├── .kicker      上标标签（字距 .52em，金色）
├── h1           38pt 衬线，`<em>` 转金色
├── .sub         11pt，max-width 96mm
├── .cover .heroes  绝对定位贴底，三张立绘
└── .cover .meta    底部信息条，压在渐变层上
```

**坑**：`.meta` 直接压在立绘上会读不出来（原来那行字正好落在角色腿上）。必须加底部渐变：

```css
.cover .meta{ position:relative; z-index:2; }
.cover::before{ /* 底部 60mm 由透明到 --bg 的渐变 */ }
```

**立绘宽度**：三张立绘宽高比差异很大（0.30~0.52），统一用 `height` 定高、宽度自适应，别用 `width`。

### 2. 章节页 `.h2`

```html
<div class="page">
  <div class="h2">标题 <small>副标题</small></div>
  ...
</div>
```

罗马数字由 CSS counter 自动生成，**不手写**：

```css
body{ counter-reset:sec; }
.h2{ counter-increment:sec; }
.h2::before{ content:counter(sec,upper-roman); }   /* Ⅰ Ⅱ Ⅲ … */
```

改动顺序、插页、删页，编号自动重排。`::after` 是一段 26mm 的短金线叠在细边线上，做出"起笔"效果。

**高度占用**：15.5pt × 1.34 + 2.6mm padding + 4mm margin ≈ **16 mm**。正文还剩 255 mm。

### 3. 角色单页卡（一角色一页）

```html
<div class="charTop">        <!-- 124mm 高，flex -->
  <div class="art">           <!-- 56%，立绘 -->
  <div class="info">          <!-- 44%，名称/CV/简介 -->
</div>
<div class="skcol">           <!-- 三列技能全文 -->
  <div class="skb">…</div> ×3
</div>
<div class="animrow">         <!-- 36mm，底部三张动画首帧 -->
```

| 区块 | 高度 | 内容 |
| :--- | --: | :--- |
| `.h2` | 16 mm | 页眉 |
| `.charTop` | 124 mm | 立绘 + 资料 |
| `.skcol` | ~96 mm | 三条技能全文（7.2pt，不截断） |
| `.animrow` | 36 mm | idle / action / 爆裂 首帧 |
| 合计 | ~272 mm | 贴着 271.5 的上限 |

**为什么是 124mm 不是 137mm**：137 时加上技能区会溢 12mm，最后一列技能被裁。124 是实测能塞下 QUEEN 690 字全文的最大值。

**`.art` 必须 `align-self:stretch`**：

```css
.charTop .art{ flex:0 0 56%; align-self:stretch; }   /* ✅ */
.charTop .art{ flex:0 0 56%; align-self:flex-start; } /* ❌ */
```

`flex-start` 会让 `.art` 高度由内容决定，`img{height:100%}` 退化成 `auto`，窄立绘（埃癸斯 0.301）按 `width:100%` 撑到 **270mm 高、盖住整页**。

**技能区不能压字号换页数**：三条技能全文 + 动画首帧是硬需求，压到 7.2pt 已是下限。要减页数只能减角色，不能减内容。

### 4. 方形图墙 `.wall6`（6 张/页）

2048×2048 方图专用（剧情插画）。

```css
.wall6{ grid-template-columns:1fr 1fr; gap:3.4mm 4mm; }
.wall6 img{ height:74mm; object-fit:contain; }
```

| 张数/页 | 单张尺寸 | 评价 |
| --: | :--- | :--- |
| 2 | 87 × 87 mm | 下面空 177mm，浪费三分之二 |
| 4 | 87 × 87 mm | 底部还空 90mm |
| **6** | **87 × 74 mm** | 整页排满，缩略图也认得出 |

### 5. 三列墙 `.wall3`（8 张/页）

512×400 的教学图专用。3 列 × 8 张，单张 57mm 宽，仍能看清箭头和按钮。原来 2 列 × 4 张只占上半页。

### 6. 两列图墙 `.wall2`（4 张/页）

通用，图注带实测尺寸（用 `imgsize(p)` 读，不写死）。

### 7. 图标栅格 `.icons`（**8 列**）

```css
.icons{ grid-template-columns:repeat(8,1fr); gap:2.2mm; }
.icons figcaption{ font-size:6.4pt; }
```

**6 列会横向溢出**：15 个图标 6 列要 3 行（96mm），8 列只要 2 行（52mm），差的正是那 40mm。

**必须给栅格里的 figure 压掉 `min-width:auto`**：

```css
.page figure{ min-width:0; }
.page figcaption{ overflow:hidden; }
```

栅格 item 默认 `min-width:auto`，长文件名的 `nowrap` 图注会把列撑宽，**8 列被切在页外**。

### 8. 成对/小阵列

| 类 | 列 | 图高 | 用途 |
| :--- | :-: | --: | :--- |
| `.pair2` | 2 | 52 mm | 两张同尺度对照（47/48 章总览） |
| `.row3` | 3 | 46 mm | 三张并排 |
| `.p2` / `.p4` | 2 / 4 | 45 / 52 mm | 通用阵列 |
| `.side4` / `.side5` | 4 / 5 | 56 / 44 mm | 带标题的小卡 |
| `.skinrow` | 5 | 定高 | 概览页底部皮肤缩略带 |

`.skinrow` 必须定高：竖版立绘按 `width:100%` 会把整页撑爆。

### 9. 表格

| 类 | 字号 | 用途 |
| :--- | --: | :--- |
| 默认表 | 9pt | 一般信息表 |
| `.tight` | 7.4pt / line-height 1.32 | 收录清单（31 行） |
| `.act` | 6.8pt / line-height 1.16 | 活动收益（稠密） |

8.1pt 的收录清单会超 257mm 被裁，7.4pt 刚好。

### 10. 说明块

| 类 | 位置 | 是否进简版 |
| :--- | :--- | :-: |
| `.lead` | 标题下导语（`--ink-2`，9pt） | ✅ |
| `.note` | 页脚注释（`--mut`，8pt） | ❌ 简版删 |
| `.warn` | 金色左边框警示块 | ❌ 简版删 |
| `.sample` | 原文摘录（等宽，`--panel` 底 + 金色左边框） | 按页 |

## 四、密度预算（本期实测）

| 页型 | 图/页 | 实测页数 | 备注 |
| :--- | --: | --: | :--- |
| 封面 | 3 | 1 | 三张立绘 |
| 概览 | 8 | 1 | 3 角色卡 + 5 皮肤缩略 |
| 角色单页卡 | 7 | 3 | 立绘 1 + 技能图标 3 + 首帧 3 |
| 皮肤 | 2~3 套/页 | 2 | 每套 1 立绘 |
| 活动 | 2~17 | 6 | 插画 6/页、教学图 8/页、图标 15/页 |
| 主线场景 | 6 | 3 | 总绘图 + 5 站位 |
| 稠密图表 | 8 | 4 | 拆解 / 透视 |
| 纯表格 | 0 | 5 | 关卡一览 2 + 剧情文本 2 + 收录清单 1 |

**目标**：`img=0` 的页只能出现在「长表」页型上（关卡一览、剧情清单、收录清单），其余页每页至少 1 张图。

本期从 **9 页 `img=0` 收到 5 页**，且这 5 页都是长表——长表放图会挤掉数据，不值得。

## 五、页数控制的收益边界

方案书预估详版 26~30 页，实测 39 页。差距的原因是三条硬约束，**不建议再压**：

| 约束 | 为什么不能压 |
| :--- | :--- |
| 角色单页卡 | 技能全文 + 动画首帧是需求，压字号已到 7.2pt 下限 |
| 长表每章一页 | 关卡一览 3 套 × 2 章，合并必溢出；拆开又增加页数 |
| 稠密图表页 | 拆解 / 透视单张就占 60mm，一页 8 张已是密度上限 |

剩下 7 页底部空白 60~86mm，都是稠密图表页——**靠缩字号换页数已过收益边界**。

## 六、裁切判据

`.page` 的下内边距是 **11 mm**，所以：

> **底部空白 < 11 mm = 一定发生了裁切。**

```bash
python audit_pdf.py <pdf>       # 逐页量底部空白
```

原理：把页面渲染成 PNG，找最后一行墨迹，换算回 mm。`overflow:hidden` 会让内容静默消失，**数 `<img>` 标签查不出这类问题**——图在 HTML 里，只是被切在纸外。

`check_pages.py` 补另一面：按 A4 打印区逐页截 PNG 给人眼看。

| 脚本 | 查什么 |
| :--- | :--- |
| `audit_pdf.py` | 底部空白 < 11mm → 裁切；同时报每页图片数 |
| `check_pages.py` | 逐页出 PNG，人眼确认切断位置 |

## 七、内联色的禁忌

深底改造时最容易漏的是**内联样式里残留的浅色主题色**。

| 症状 | 原因 |
| :--- | :--- |
| 图注在深底上几乎看不见 | 内联 `color:#6b7488`（旧浅色主题的图注灰） |
| 加粗文字变成近黑方块 | 内联 `color:#26303f` |
| 甘特图出现白衬底 | 内联 `background:#f7f9fd` |

本期实测 20 处。**规则**：

- HTML 里只允许出现 `var(--ink)` / `var(--ink-2)` / `var(--mut)` / `var(--gold)` / `var(--panel)` / `var(--bg-deep)`
- 需要新颜色就先在 `:root` 里加变量
- 改完主题后跑一遍：`grep -c '#6b7488\|#26303f\|#f7f9fd' make_pdf_v2.py` 应为 `0`

## 八、图片缓存

`pic()` 把源图重采样进 `_构建/PDF缓存/`。缓存键 = **父目录名 + 文件名 + 源文件 mtime:size 的 md5**。

只按文件名缓存会撞车：重构后三个角色的立绘都在 `立绘/` 下，`半身像.png` 会撞成同一个缓存文件，**三张卡显示同一张图**。所以键里必须拼源路径。

指纹用 `mtime:size` 而不是内容 md5：源图重渲后（爆裂首帧这次）能自动失效，又不必每次读全文件。
