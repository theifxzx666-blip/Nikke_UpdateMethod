## 选页规则（不是「挑好看的」）

对齐 `00_规范/交付模板/简版模板.md` 的 5 章，一章一个落点：

| 章 | 找哪一页 | 判断特征 | 本期落点 |
| :-: | :--- | :--- | --: |
| 1 本期有什么 | 标题含「本期都有什么 / 一眼看完」 | 一张多行总表 | 1 |
| 2 新角色 | 标题形如「新角色 · XXX」 | **不是**「技能详情 · XXX」 | 2 / 3 / 4 |
| 3 新皮肤 | 标题形如「新皮肤 a–b / n」 | 只取第一页，装不下就算了 | 5 |
| 4 活动与主线 | 「活动 · …」+「本期主线 · …」 | 主线取总览页，不取地图 / 关卡表 | 7 / 13 |
| 5 素材汇总表 | 标题含「收录了什么 / 汇总」 | 类别 × 数量 × 说明三列表 | **38** |

## 简版自检（5 条，缺一不可）

```bash
BRIEF=1 <VENV_PY> make_pdf_v2.py                 # 出简版，控制台会打印白名单与删除清单
<VENV_PY> audit_pdf.py <简版.pdf>                 # 底部空白 < 11mm 即裁切
```

| # | 项 | 通过条件 |
| :-: | :--- | :--- |
| 1 | 页数 | 8~12 页，且与白名单长度相等 |
| 2 | 五章齐 | 本期有什么 / 新角色 / 皮肤 / 活动 / 主线 / 汇总表都能找到 |
| 3 | 技术词 | `Timeline` / `Spine` / `bundle` / `UnityPy` / `.lss` / `adb` 全 0 命中 |
| 4 | 断链 | 简版里**不许出现「见前文 X」而 X 页已被删** |
| 5 | 裁切 | 每页底部空白 ≥ 11mm |

### 第 3 条的高发残留：`Locale_` 开头的表名

- 或者把这一行改成不引用页码的写法
