# 08 · 交付 PDF

**路线：Python 拼 HTML → 逐页截图核对版式 → Chrome `--print-to-pdf` → 回读页数 → 简版用同一脚本删出来。**

两条铁律：

1. **一个脚本出两版**（详版 / 简版）。另写一个脚本必然两份数据各自维护，一定会分裂（E-03）。
2. **不许「命令返回 0」就宣布成功**。必须回读页数 + 抽 2 页转 PNG 目视（E-28）。
   同理**不许只量中间数据**：留白 / 页数一律从成品 PDF 量，不从 HTML 的 `.page` 高度推（E-63）。

---

## 触发条件

- 本期素材收完，要出《YYYY-MM-DD 更新内容一览》
- 改完版式要核对有没有溢出裁切
- 要一份给「不想看方法论」的读者看的简版

## 输入 / 输出

| 方向 | 内容 |
| :--- | :--- |
| 输入 | 两段式交付目录（`01_新角色&皮肤` / `02_主线&活动`）+ `_素材清单.csv` |
| 输出 | `<期次>/YYYY-MM-DD_更新内容一览.pdf`（详版）/ `YYYY-MM-DD_更新内容简版.pdf`（简版）/ `_构建/报告.html` |

**版式规范见 `reference/版式.md`，页序与简版白名单见 `reference/页序与简版选页.md`。**
改版式只改 `make_pdf_v2.py` 里的 `CSS` 常量，不写内联色。

---

## 步骤

### 1. 数据先落地，再拼页

**页面上出现的每个数字，都必须来自文件，不许在脚本里写死。**

| 数字 | 唯一出处 |
| :--- | :--- |
| 素材数量（分类 × 文件数） | `_素材清单.csv` 按 `kind` 分组计数 |
| 活动数 / 剧情条数 | `02_主线&活动/00_往期活动索引/往期活动清单.tsv` 的行数与「条目数」列求和 |
| 技能数值 | `SkillInfoTable.json`（`SkillLevel=10`） |
| 角色名 / 技能名 / 简介 | `Locale_Character` / `Locale_Skill` |
| 章节关卡 | `02_主线&活动/主线_.../01_章节与关卡/*.tsv` |

改完数据 → 重跑 PDF，数字自动跟着变。**不要手改 PDF，也不要在 HTML 里手改数。**

### 2. 逐页核对版式（改一次跑一次）

`.page` 是 `height:296.5mm + overflow:hidden`，**内容超了会被静默裁掉**，不报错。

两个脚本查两面，缺一不可：

```bash
# A. 量底部空白：空白 < 11mm 即判定裁切（下内边距就是 11mm）
python <ROOT>/05_脚本/主线/audit_pdf.py <pdf>

# B. 出 PNG 人眼确认切断位置（满出血口径 794 × 1121 px）
python <ROOT>/05_脚本/主线/check_pages.py 3 30 38     # 只截这几页（1 起）
python <ROOT>/05_脚本/主线/check_pages.py             # 全部页
python <ROOT>/05_脚本/主线/check_pages.py --html <报告_简版.html> --out <临时目录>
```

**`audit_pdf.py` 比数 `<img>` 标签准**：`overflow:hidden` 裁掉的内容在 HTML 里还在、在纸面上没了，
数标签查不出来（图注文字被切断也同理）。

`check_pages.py` 的截图尺寸必须跟 `.page` 一致（210 × 296.5 mm → 794 × 1121 px）。
换版式不换这里，截出来是缩放的，判断不了真实裁切位置。

### 3. 出详版 PDF

```bash
python <ROOT>/05_脚本/主线/make_pdf_v2.py            # → YYYY-MM-DD_更新内容一览.pdf
python <ROOT>/05_脚本/主线/make_pdf_v2.py --html-only  # 只出 HTML，调版式时用
```

Chrome 参数一个都不能少：

| 参数 | 少了会怎样 |
| :--- | :--- |
| `--headless=new` | 旧 headless 不出中文字形 |
| `--no-pdf-header-footer` | 每页多出 URL + 日期页眉页脚 |
| `--allow-file-access-from-files` | 本地 `file:///` 图片全部不显示（图丢成空白） |
| `--virtual-time-budget=25000` | 图片没加载完就打印，后半本全是空白 |
| `--print-to-pdf` 指向**临时文件** | 目标被阅读器占用时 Chrome **静默失败**，脚本却读到旧文件大小，看着像成功 |

最后写 `os.replace(临时, 目标)`，`OSError` 时提示「关闭阅读器后改名」。

### 4. 回读页数（必做）

```bash
python -c "import re;d=open('xxx.pdf','rb').read();print(len(re.findall(rb'/Type\s*/Page[^s]',d)))"
```

与 `报告.html` 里 `<div class="page">` 的个数**必须相等**。不等就是有页被撑成两页（内容溢出）
或有页没渲染。

本期基线：**详版 39 页 / 54.8 MB**。

### 5. 简版：同一个脚本，删出来

```bash
BRIEF=1 python <ROOT>/05_脚本/主线/make_pdf_v2.py
# 页序变了就显式指定：
BRIEF=1 BRIEF_PAGES=0,1,2,3,4,5,7,13,38 python <ROOT>/05_脚本/主线/make_pdf_v2.py
```

机制（都在 `make_pdf_v2.py` 里）：

| 环节 | 做法 |
| :--- | :--- |
| 选页 | `BRIEF_PAGES` 页索引白名单（0 起），其余整页丢弃 |
| 去注释块 | `_drop_block()` 按**标签深度配对**删 `.note` / `.warn`，不用懒惰正则（会截断半截标签） |
| 去技术词 | `BRIEF_REWRITE` 把 Spine→骨骼动画、Timeline→时间轴、bundle→资源包… 只作用于白名单页 |
| 自检 | 删完扫 `BRIEF_WORDS`，仍有残留就打印 `!!` 警告 |
| 产物 | `报告_简版.html` + `YYYY-MM-DD_更新内容简版.pdf` |

本期基线：**简版 9 页 / 15.2 MB**（白名单 `0,1,2,3,4,5,7,13,38` = 封面 / 本期有什么 / 三名角色 / 皮肤 / 活动 / 主线 / 素材汇总）。

**白名单每期都要重新核对页序**：先用 `--html-only` 看一遍页标题，确认选中的是对应章节，
再出 PDF。页序错位是简版最常见的翻车——本期就踩过：写成 `36`（角色大厅站立动画）
而不是 `38`（收录清单），结果缺了「素材汇总表」整章、还塞进一页 Spine 技术页。
**照着页标题核，不要凭页码印象。**

### 6. 简版自检（5 条，缺一不可）

1. 页数在 8~12，且等于白名单长度（`audit_pdf.py <简版.pdf>` 看页数）
2. 全文搜 `Timeline` / `Spine` / `bundle` / `UnityPy` / `脚本` / `.lss` / `adb` / `Locale_` → **0 命中**
3. **无断链**：不许出现「见前文 X」而 X 页已被删掉（本期踩过：活动页引用「CE009 更正页」，那页在简版里不存在）
4. 素材汇总表的数字与详版同章**逐项相等**（同源，不另算）
5. 每页底部空白 ≥ 11mm，`check_pages.py --html 报告_简版.html` 无破图

## 校验

| # | 项 | 通过条件 |
| :-: | :--- | :--- |
| 1 | 页数 | PDF 实际页数 == HTML 的 `.page` 个数 |
| 2 | 溢出 | `audit_pdf.py` 全部页底部空白 ≥ 11mm（**量 PDF 成品，不量 HTML / CSS 预算**，见 E-63），且 `check_pages.py` 抽看过 |
| 3 | 破图 | 每页都有图；无「框在字在图不在」 |
| 4 | 数字同源 | 汇总表数字 == `_素材清单.csv` 的 `kind` 分组计数 |
| 5 | 简版纯度 | 技术词 0 命中，`.note`/`.warn` 0 个，无断链 |
| 6 | 两版一致 | 简版每个数字都能在详版找到相同值 |
| 7 | 占用 | 目标 PDF 可被其他程序打开（不是只写了一半的临时文件） |
| 8 | 满出血 | 抽一页 `check_pages.py` 出图，四角像素 = `#231f1e`，无白边 |

## 失败退路

| 现象 | 处理 |
| :--- | :--- |
| 命令返回 0 但 PDF 没更新 | 目标被阅读器占用。Chrome 静默失败 → 看是否生成了 `_报告.pdf` 临时文件 |
| 后半本图片全是空白 | 少了 `--virtual-time-budget`，或图路径不是 `file:///` 绝对 URI |
| 某页被撑成两页 | 内容超 271.5mm 内容区。`audit_pdf.py` 定位到页号 → 砍内容或拆页 |
| 页面四边有白框 | `@page margin` 没设 0，或 `.page` 没带底色 |
| 图注在深底上几乎看不见 | 内联样式里残留旧浅色主题色（`#6b7488` / `#26303f` / `#f7f9fd`） |
| 三张卡显示同一张图 | `pic()` 缓存键没拼源路径 → 父目录同名时撞车 |
| 窄立绘盖住整页 | `.charTop .art` 用了 `align-self:flex-start`，应改 `stretch` |
| 图标列被切在页外 | 栅格 `figure` 没压 `min-width:0`，长图注把列撑宽 |
| 简版页序不对 | 加了/删了详版页 → 重排 `BRIEF_PAGES`（先 `--html-only` 看标题） |
| 简版仍有技术词 | 看 `!!` 警告里的词，补进 `BRIEF_REWRITE`（短词替空白，长词替人话） |
| 附件体积过大 | 图片走超采样后降采样；必要时降 `long` 边长，但**不许改数据** |
