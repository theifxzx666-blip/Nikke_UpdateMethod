## 装配顺序为什么不能换

```
01 定范围 ──► 02 取资源 ──► 05 渲动画 ──┐
                    │                    ├─► 06 出 PDF
                    └─► 03/04 取数据 ────┘
```

- **01 必须在最前**：不定「上期基线」，就没法判定「本期新增」，采多了是浪费、采少了要重跑。
- **03/04 与 02 并行**：静态表和文本走的是 `.lss`，与包不冲突，可以同时开工。
- **05 必须在 02 之后**：渲的是 02 拿到的三件套。
- **06 必须在最后**：它的每个数字都来自前面的产物（见 `06-deliver-pdf/SKILL.md` 第 1 步的表）。

## 跨 Skill 的三条共用约定

| 约定 | 说明 |
| :--- | :--- |
| **数字只有一个出处** | 对外报数只用 `01_采集明细/采集明细_总表.csv` 与 `00_活动清单.tsv`，不许另算 |
| **验收必须逐帧/逐页** | GIF 出全帧网格，PDF 逐页截图 —— 抽查首帧/单页会刚好避开坏样本 |
| **失败就停，不硬解** | 脚本报「不可归组 ≠ 0」「未覆盖类型」「表里没有」时停下问，不猜、不编 |
