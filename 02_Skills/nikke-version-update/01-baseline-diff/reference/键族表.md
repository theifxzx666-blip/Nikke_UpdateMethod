# 键族表（bundle 命名规律）

> 全部来自 `20260813_国际服` 实测，包名原样抄录，未做美化。
> 新增前缀补进 `scripts/diff_keys.py` 的 `FAMILY` 表。

---

## 一、格式总则

```
<分组前缀>_assets_<相对路径>/<资源名>_<32 位 hash>.bundle
```

- 第二段 `assets` 是固定分隔符
- 第三段起是包内相对路径，可能带子目录（`spine/standing/c870/`）
- 结尾 32 位十六进制 hash，`catalog` 里的键与之一一对应
- 少数没有 `_assets_` 段（`audiogroup...`、`catalog.db`）

## 三、资源编号规则

| 形态 | 含义 | 例 |
| :--- | :--- | :--- |
| `c<3 位数字>_<2 位数字>` | 角色 ID + 时装序号 | `c870_00` = QUEEN 默认，`c870_01` = 秀尽学园学生会长 |
| `ce<3 位数字>` | 活动代号 | `ce009` = PERSONA ON FRONTLINE |
| `chap_<章>_<序>` | 主线剧情段 | `chap_47_01` |
| `xba0\d\d` / `eba0\d\d` | BOSS 型号 | `xba003`（安尼希利奥）、`eba002`（莉贝雷利奥躯体） |
| `event_<YYMMDD>` | 更新分期包（`saus/raw` 下） | `event_260813` |

**时装序号 `_01` 以后没有独立的爆裂包** —— 每角色只有 `_00` 一份爆裂包，多套时装共用。
立绘/小人/大厅站立则是每时装一份。

## 五、更新分期包（链 A0，判断「这天开了什么」的最快路径）

```
saus/raw/ 下的 event_<YYMMDD>.lsc：
event_260423  event_260514  event_260528  event_260611  event_260702
event_260723  event_260813  event_260903  event_260917  event_261008
```

每张是 `sprite` + `locale` 两表，**`sprite` 里只装该期上架的 BANNER 图**，下架即消失。
相邻两期做 `sprite.name` 集合差 → 直接得到「这期上了什么」。

- 输入只有 1~2 MB，分钟级，**不依赖 20 GB 基线**
- `sprite.texture` 不加密，是 ASTC 5×5：`len == ceil(w/5) × ceil(h/5) × 16`
- 解码：`texture2ddecoder.decode_astc(d, w, h, 5, 5)` → 按 **BGRA** 取 → **垂直翻转**
- 归一：`base = name 去掉 '<lang>/' 前缀`；丢弃 `_S` 结尾（328×108 缩略版）
- 脚本：`lsc_sprite.py <event_YYMMDD.dec> <输出目录>`

**开服当天第一件事就跑这个** —— 即使基线环节出问题，也能先出「今天开了什么」。
