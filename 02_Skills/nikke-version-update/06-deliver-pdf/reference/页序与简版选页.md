## 选页规则（不是「挑好看的」）

对齐 `00_规范/交付模板/简版模板.md` 的 5 章，一章一个落点：

| 章 | 找哪一页 | 判断特征 |
| :-: | :--- | :--- |
| 1 本期有什么 | 标题含「本期都有什么 / 一眼看完」 | 一张 6 行表 |
| 2 新角色 | 标题形如「新角色 · XXX」 | **不是**「技能详情 · XXX」 |
| 3 活动与主线 | 「活动 · …」+「本期主线 · …」 | 主线取总览页，不取地图 / 关卡表 |
| 4 素材汇总表 | 标题含「收录了什么 / 汇总」 | 分类 × 数量 × 说明三列表 |
| 5 明细表目录 | 通常没有独立页 → 合在素材汇总页的说明块里 | 若当期有独立页再加 |

## 不能选的页（选了必翻车）

| 页型 | 为什么不能进简版 |
| :--- | :--- |
| 技能详情 | 含 `SkillInfoTable`、`DescriptionLocalkey`、占位符填充说明 —— 方法论 |
| 爆裂特写 / 3D 查看器 / 大厅动画 | 含 Timeline、Spine、骨骼、轨道 —— 技术路数 |
| 「怎么渲的」「数据边界」「更正」 | 全是过程与翻车复盘，属详版 |
| 剧情清单 | 174 行的表，简版读者不看 |
