# 06 · 交付 PDF

**路线：Python 拼 HTML → 逐页截图核对版式 → Chrome `--print-to-pdf` → 回读页数 → 简版用同一脚本删出来。**

两条铁律：

1. **一个脚本出两版**（详版 / 简版）。另写一个脚本必然两份数据各自维护，一定会分裂（E-03）。
2. **不许「命令返回 0」就宣布成功**。必须回读页数 + 抽 2 页转 PNG 目视（E-28）。

---

## 触发条件

- 本期素材收完，要出《YYYY-MM-DD 更新内容一览》
- 改完版式要核对有没有溢出裁切
- 要一份给「不想看方法论」的读者看的简版

## 输入 / 输出

| 方向 | 内容 |
| :--- | :--- |
| 输入 | 分类交付目录（`01_新角色` … `07_角色爆裂特写`）+ `01_采集明细/采集明细_总表.csv` |
| 输出 | `<期次>/YYYY-MM-DD_更新内容一览.pdf`（详版）/ `YYYY-MM-DD_更新内容简版.pdf`（简版）/ `_构建/报告.html` |

---

## 步骤

### 1. 数据先落地，再拼页

**页面上出现的每个数字，都必须来自文件，不许在脚本里写死。**

| 数字 | 唯一出处 |
| :--- | :--- |
| 素材数量（分类 × 文件数） | `01_采集明细/采集明细_总表.csv`（36 行） |
| 活动数 / 剧情条数 | `04_剧情文本/活动剧情/00_活动清单.tsv` 的行数与「条目数」列求和 |
| 技能数值 | `SkillInfoTable.json`（`SkillLevel=10`） |
| 角色名 / 技能名 / 简介 | `Locale_Character` / `Locale_Skill` |
| 章节关卡 | `02_章节与关卡/*.tsv` |

改完数据 → 重跑 PDF，数字自动跟着变。**不要手改 PDF，也不要在 HTML 里手改数。**

### 2. 逐页核对版式（改一次跑一次）

`.page` 是 `height:266mm + overflow:hidden`，**内容超了会被静默裁掉**，不报错。

```bash
python <ROOT>/05_脚本/主线/check_pages.py 39 48      # 只截这几页（1 起）
python <ROOT>/05_脚本/主线/check_pages.py            # 全部页
python <ROOT>/05_脚本/主线/check_pages.py --html <报告_简版.html> --out <临时目录>
```

按 A4 实际打印区（`@page margin:13mm 13mm 14mm` → 184mm × 266mm = **696 × 1006 px**）逐页出 PNG。
看图只看一件事：**底部有没有被切断**（表格最后一行只出半行、图片下沿平齐且文字消失）。

### 3. 出详版 PDF

```bash
python <ROOT>/05_脚本/主线/make_pdf_v2.py            # → YYYY-MM-DD_更新内容一览.pdf
python <ROOT>/05_脚本/主线/make_pdf_v2.py --html-only  # 只出 HTML，调版式时用
```

Chrome 参数一个都不能少：

| 参数 | 少了会怎样 |
| :--- | :--- |
| `--headless=new` | 旧 headless 不出中文字形 |
| `--no-pdf-header-footer` | 每页多出 URL + 日期页眉页脚 |
| `--allow-file-access-from-files` | 本地 `file:///` 图片全部不显示（图丢成空白） |
| `--virtual-time-budget=25000` | 图片没加载完就打印，后半本全是空白 |
| `--print-to-pdf` 指向**临时文件** | 目标被阅读器占用时 Chrome **静默失败**，脚本却读到旧文件大小，看着像成功 |

最后写 `os.replace(临时, 目标)`，`OSError` 时提示「关闭阅读器后改名」。

### 4. 回读页数（必做）

```bash
python -c "import re;d=open('xxx.pdf','rb').read();print(len(re.findall(rb'/Type\s*/Page[^s]',d)))"
```

与 `报告.html` 里 `<div class="page">` 的个数**必须相等**。不等就是有页被撑成两页（内容溢出）
或有页没渲染。

本期基线：**详版 48 页 / 51.1 MB**。

### 5. 简版：同一个脚本，删出来

```bash
BRIEF=1 python <ROOT>/05_脚本/主线/make_pdf_v2.py
# 页序变了就显式指定：
BRIEF=1 BRIEF_PAGES=0,1,2,4,6,11,21,47 python <ROOT>/05_脚本/主线/make_pdf_v2.py
```

机制（都在 `make_pdf_v2.py` 里）：

| 环节 | 做法 |
| :--- | :--- |
| 选页 | `BRIEF_PAGES` 页索引白名单（0 起），其余整页丢弃 |
| 去注释块 | `_drop_block()` 按**标签深度配对**删 `.note` / `.warn`，不用懒惰正则（会截断半截标签） |
| 去技术词 | `BRIEF_REWRITE` 把 Spine→骨骼动画、Timeline→时间轴、bundle→资源包… 只作用于白名单页 |
| 自检 | 删完扫 `BRIEF_WORDS`，仍有残留就打印 `!!` 警告 |
| 产物 | `报告_简版.html` + `YYYY-MM-DD_更新内容简版.pdf` |

本期基线：**简版 8 页 / 6.57 MB**（白名单 `0,1,2,4,6,11,21,47` = 封面 / 本期有什么 / 三名角色 / 活动 / 主线 / 素材汇总）。

**白名单每期都要重新核对页序**：先用 `--html-only` 看一遍页标题，确认选中的是对应章节，
再出 PDF。页序错位是简版最常见的翻车（选中了「技能详情」而不是「新角色」）。

### 6. 简版自检（4 条，缺一不可）

1. 页数在 8~14，每页无溢出（`check_pages.py --html 报告_简版.html` 过一遍）
2. 全文搜 `Timeline` / `Spine` / `bundle` / `UnityPy` / `脚本` / `.lss` / `adb` → **0 命中**
3. 素材汇总表的数字与详版同章**逐项相等**（同源，不另算）
4. 每页截图看一遍，无破图（本地 `file:///` 图片缺失是高发问题）

## 校验

| # | 项 | 通过条件 |
| :-: | :--- | :--- |
| 1 | 页数 | PDF 实际页数 == HTML 的 `.page` 个数 |
| 2 | 溢出 | `check_pages.py` 逐页看过，底部无切断 |
| 3 | 破图 | 每页都有图；无「框在字在图不在」 |
| 4 | 数字同源 | 汇总表数字 == `01_采集明细/采集明细_总表.csv` |
| 5 | 简版纯度 | 技术词 0 命中，`.note`/`.warn` 0 个 |
| 6 | 两版一致 | 简版每个数字都能在详版找到相同值 |
| 7 | 占用 | 目标 PDF 可被其他程序打开（不是只写了一半的临时文件） |

## 失败退路

| 现象 | 处理 |
| :--- | :--- |
| 命令返回 0 但 PDF 没更新 | 目标被阅读器占用。Chrome 静默失败 → 看是否生成了 `_报告.pdf` 临时文件 |
| 后半本图片全是空白 | 少了 `--virtual-time-budget`，或图路径不是 `file:///` 绝对 URI |
| 某页被撑成两页 | 内容超 266mm。`check_pages.py` 单截这页确认，砍内容或拆页 |
| 简版页序不对 | 加了/删了详版页 → 重排 `BRIEF_PAGES`（先 `--html-only` 看标题） |
| 简版仍有技术词 | 看 `!!` 警告里的词，补进 `BRIEF_REWRITE`（短词替空白，长词替人话） |
| 附件体积过大 | 图片走超采样后降采样；必要时降 `long` 边长，但**不许改数据** |
