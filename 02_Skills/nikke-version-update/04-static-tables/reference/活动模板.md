# 活动奖励模板：17 页结构与口径

## 一、两张表，别混

| 文件 | 页数 | 用途 |
| :--- | --: | :--- |
| `活动模板收益_zh-CN.xlsx` | **7 页** | 跨期对照（84 期），横向比同组数值 |
| `<活动名>_活动收益_zh-CN.xlsx` | **17 页** | 单期交付，一个活动一份 |

## 二、17 页页序（实测 `PERSONA ON FRONTLINE` 版）

| # | 页签 | 内容 |
| :-: | :--- | :--- |
| 0 | `活动概览` | 活动代号 / 天数 / 组别 / 关键数字 |
| 1 | `活动关卡奖励` | 主线关（一次性 + 可重复）逐关掉落 |
| 2 | `挑战关卡` | 挑战关首通与重复 |
| 3 | `活动任务` | 任务条数与逐条奖励 |
| 4 | `签到印章` | 签到档数与逐档 |
| 5 | `活动商店兑换` | 商品项数 + 单价 + 限购 |
| 6 | `其他产出` | 地图拾取等零散来源 |
| 7 | `活动经济` | 货币收支平衡 |
| 8 | `剧情目录` | 剧情条目索引（正文归 `05-text-locale`） |
| 9 | `数据链路` | 每个数字来自哪张表哪个字段 |
| 10 | `小游戏·难度` | ← 无小游戏则删 |
| 10b | `小游戏·计分常量` | ← 无小游戏则删 |
| 11 | `小游戏·任务` | ← 无小游戏则删 |
| 12 | `小游戏·道具敌人` | ← 无小游戏则删 |
| 13 | `地图·遗失物品` | 点位 + 物品 |
| 14 | `地图·隐藏道具` | 点位 + 物品 |
| 15 | `收益汇总` | **对外报数只认这一页** |

小游戏那 4 页（`10` / `10b` / `11` / `12`）**整组删**，删完是 **13 页**。
删了必须在 `说明.md` 写明「本期无小游戏，已删 10/10b/11/12」，不要静默。

## 三、跨期对照表的 7 页

| 页签 | 用途 |
| :--- | :--- |
| `0_分组总览` | 三组的样本数与区间 |
| `1_有地图_逐期` | 21 天 / 28 天两类，逐期一行 |
| `2_无地图_逐期` | 剧情活动，逐期一行 |
| `3_固定项_可直接套` | 每期都一样、能直接照抄的 |
| `4_可变项_必须单取` | 每期都要重算的 |
| `5_单期总量_落地` | 单期合计 |
| `6_数据链路` | 字段级来源 |

新增一期 = 在 `1_` 或 `2_` 表尾追加一行，并把 `0_` / `5_` 的统计口径重算。

## 四、一次性 / 可重复绝不混算

`15_收益汇总` **分两段**：

```
一次性：关卡首通 + 挑战首通 + 签到 + 任务
可重复：关卡重复刷 + 每日门票 × 天数
```

同段落内同名相加，**绝不跨段累加**。混了就会把「每日 5 张门票」
当成一次性产出，整张表虚高。

## 五、已知偏差（登记，不改脚本）

复算脚本与归档表在 **79/84** 期逐值一致。剩 5 期：

| 事件 Id | 差异 |
| :--- | :--- |
| `40001` | 一次性主机低 2 |
| `40006` | 低 3 |
| `80100` | 低 23 |
| `80200` | 低 2 |
| `81600` | 低 2 |

原因：2022~2023 的旧结构把主机塞进挑战首通或地图产出，与现行「主机独立成项」不同。
**登记即可，不许为了凑这 5 期去改算法** —— 改了会让 79 期全部错。

## 六、字段级数据链路（写 `9_数据链路` 页时照抄）

| 口径 | 来源 |
| :--- | :--- |
| 活动代号 | `EventManagerTable.EventBannerResourceId` 去掉 `EVENT_BANNER_` 与尾部 `_S` |
| 天数 | `FieldItemTable` 的 `Despawn − Spawn`（**不是** `ScheduleValue`，后者全服恒 0） |
| 子模块 | `EventManagerTable.ParentsEventId` 反查（**不按 Id 位数猜**） |
| 关卡组 | `EventDungeonTable.DifficultGroup` 取后三位匹配 |
| 一次性 / 可重复 | `EventDungeonStageTable.IsRepeatClear` |
| 主机 | `ItemPieceTable.ItemSubType == 14`（8 件：5 企业 + 3 职业） |
| 商店 | `sys=11` 存在 **且** `ContentsShopTable.BgResourceId` 匹配 |
| 活动称号 | `USERTITLE_NAME_<banner代号>` |
